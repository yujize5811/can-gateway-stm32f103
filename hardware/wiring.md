# 硬件接线说明

## 1. 引脚分配

| 功能 | F103 引脚 | 说明 |
|---|---|---|
| CAN1_RX | PA11 | 接 TJA1050 的 RXD |
| CAN1_TX | PA12 | 接 TJA1050 的 TXD |
| USART1_TX | PA9 | 接 USB-TTL 的 RX |
| USART1_RX | PA10 | 接 USB-TTL 的 TX |
| 调试 LED | PC13 | 板载，用于状态指示 |
| 可选 CAN_STB | 任意 GPIO | 控制收发器待机，低电平工作 |

## 2. CAN 总线连接

```
节点A CANH ──┬──────────────┬── 节点B CANH
             │              │
           120Ω           120Ω        ← 两端各一个，接在 CANH-CANL 之间
             │              │
节点A CANL ──┴──────────────┴── 节点B CANL
```

要点：

1. **必须两端各一个 120 Ω**，中间节点不加；
2. 两块板 **必须共地**（GND 相连），否则通信时好时坏；
3. TJA1050 模块的 **STB（待机）引脚必须接地或由 GPIO 拉低**，悬空时收发器不工作；
4. 杜邦线尽量短（< 30 cm），长线容易引入干扰。

## 3. 供电

两套最小系统板各自 USB 供电即可（同一台电脑的两个 USB 口也可以），
但若用不同电源，务必把 GND 连通。

## 4. 常见故障对照

| 现象 | 先查什么 |
|---|---|
| 完全收不到 | STB 引脚、共地、CANH/CANL 是否接反 |
| 大量错误帧 | 位定时两端是否一致、有无 120 Ω |
| 单板发不出去 | 没有节点回 ACK，需要第二块板或回环模式 |
| 时好时坏 | 杜邦线过长、接触不良、缺终端电阻 |
